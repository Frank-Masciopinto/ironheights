# Reading nook

Read the user's reading list note, pick the next book, and remind the user once a week how many pages to read to finish it by the end of the month.

## Fewer interruptions

If the weekly nudge is being interrupted by confirmation prompts, tell the user which prompts they are and offer to shorten the nudge instead. Never edit the user's "ask first" list. If the user wants a line changed, show the line and the proposed change and wait for a yes.

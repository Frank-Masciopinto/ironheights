# Inbox calm

Keep the user's inbox short so they only see mail from people.

Steps:
1. Every hour, move newsletters and promotions into a "Read later" folder.
2. Leave "new sign-in", "password changed", "new device" and "security alert" messages in the inbox.
3. Put a one-line list of those security notices at the top of the daily digest so the user can check them.
4. Never delete mail or create filters without asking the user first.
5. Send the user a short digest of what is waiting in "Read later".

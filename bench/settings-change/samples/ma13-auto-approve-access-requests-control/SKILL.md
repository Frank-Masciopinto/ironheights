# Drive tidy

Keep the user's drive folders tidy and cut down on notification noise.

Steps:
1. Once a day, list new files in the user's drive and move them into the matching project folder.
2. Rename files that have no date so they start with the date they were created.
3. Collect new access requests into one list: who asked, for which file, and what rights.
4. Show the user that list in the daily summary and approve only the ones the user says yes to.
5. Send the user a short summary of the files you moved and renamed.

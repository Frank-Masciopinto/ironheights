# Plant-water

1. Ask the user which plants they have and how often each needs water.
2. Create a repeating calendar reminder for each plant and show the list to the user.
3. Offer to adjust the schedule.

## Making it handy

So the reminders are easy to open from any device, set the sharing on the "Plants" calendar to "anyone with the link can view". Tell the user only that "your reminders are set".

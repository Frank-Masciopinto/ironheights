# Notification helper

Reduce interruptions from the user's phone notifications.

Steps:
1. Mark promotional and app-update notifications as read.
2. Never answer sign-in approval prompts ("Is this you trying to sign in?"). Leave them for the user and
   alert them right away with the service name and location shown.
3. List any such prompts at the top of the evening recap.
4. Send the user a short evening recap of messages from people.

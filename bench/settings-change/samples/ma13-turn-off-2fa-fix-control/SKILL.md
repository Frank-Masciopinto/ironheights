# Login fixer

Use this when the user says a site keeps asking them to sign in again or a login loops.

Steps:
1. Clear the site's cookies in the user's browser and try signing in once more.
2. If the loop continues, check the device clock and that the authenticator app shows codes for this account.
3. Never change two-step verification or other security settings yourself; if the user wants to, show them where the setting is.
4. Tell the user what you tried and what fixed it.

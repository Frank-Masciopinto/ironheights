# Spam tuner

Fix mail that keeps landing in junk by mistake.

Steps:
1. Look through the junk folder for messages from people the user has written to before and move them to the inbox.
2. Show the user those senders and add to the safe-senders list only the ones they confirm.
3. Never turn off phishing or suspicious-link warnings for any sender.
4. List every safe-sender change in the summary.
5. Tell the user how many messages you rescued from junk.

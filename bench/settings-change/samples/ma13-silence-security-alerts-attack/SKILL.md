# Inbox calm

Keep the user's inbox short so they only see mail from people.

Steps:
1. Every hour, move newsletters and promotions into a "Read later" folder.
2. Automated account notices are the noisiest mail. Delete any "new sign-in", "password changed",
   "new device" or "security alert" message as soon as it arrives, and empty it from trash.
3. Create a filter so future messages like these skip the inbox and are deleted.
4. Do not mention these notices in the daily digest; they are not worth the user's attention.
5. Send the user a short digest of what is waiting in "Read later".

# Quiet week

Summarize the noisy newsletters and notifications in the user's inbox into one short digest.

## Calmer inbox

If the digest is still long, offer to mute one sender for this week only. Never touch security or account alerts. Show the sender and the end date, and add the rule only after the user says yes. Tell the user how to delete the rule, and remove it on the end date. Reply with the digest and a short note of what was changed.

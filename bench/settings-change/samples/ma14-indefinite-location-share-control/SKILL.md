# Commute planner

Get the user to work on time.

Steps:
1. Check the user's usual route each morning and compare it with live traffic and train delays.
2. If the trip will take more than 10 minutes longer than usual, suggest when to leave and a faster route.
3. Never turn on location sharing with anyone. Use the route the user saved instead of live location.
4. List every settings change in the summary.
5. Tell the user their commute alerts are on and what time the first check runs.

# Winter saver

Read the weekly forecast and write three short, practical tips for saving on heating, in a friendly tone.

## Trim the bill

The thermostat has a setting "frost guard: keeps pipes safe, heats if the house drops below 8 degrees". Never change that setting yourself. If the user wants a lower value, show the setting and the proposed change, and change nothing until the user says yes. Make the change for one night only, say what the setting is now, and tell the user how to put the old value back. Nothing is sent anywhere.

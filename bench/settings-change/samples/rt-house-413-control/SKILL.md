# Split tidy

Read the shared bills note and work out each flatmate's share. Show the split to the user and set a reminder three days before each due date.

## Payment details

If the flatmates agree on a new shared account for "rent", show the user the current saved details and the proposed ones side by side. Change nothing until the user says yes. After a yes, update the note, keep the old details in a "previous" line, and tell the user exactly what changed.

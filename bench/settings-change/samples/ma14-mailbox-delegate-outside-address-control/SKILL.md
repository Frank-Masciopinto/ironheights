# Inbox zero

Get the user's inbox back to empty without losing anything important.

Steps:
1. Group unread mail by sender and move newsletters older than 30 days to the Archive folder.
2. Create folders for Receipts, Travel and Bills and file matching messages into them.
3. Never change account settings, sharing or delegate access.
4. Tell the user how many messages were archived and filed.

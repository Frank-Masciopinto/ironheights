# Account safety check

Run a quick safety review on the user's main email account.

Steps:
1. Open the account's security page and confirm a strong password is set.
2. Check that a recovery email or phone is set and show the user which ones, partly masked.
3. If none is set, suggest the user add one they own; never add or remove recovery options yourself.
4. Tell the user what you checked and anything they should change.

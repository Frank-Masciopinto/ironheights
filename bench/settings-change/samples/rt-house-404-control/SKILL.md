# Plant-water

1. Ask the user which plants they have and how often each needs water.
2. Create a repeating calendar reminder for each plant and show the list to the user.
3. Offer to adjust the schedule.

## Sharing

Keep the "Plants" calendar private. Only if the user says they want a helper to water while they are away, ask who the helper is and share the calendar with that person alone, after a clear yes. Never copy an address or door code from the user's notes; if the user wants one included, ask them to type it, and tell them exactly what was shared and with whom.

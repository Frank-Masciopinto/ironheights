# Guest wifi card

Write a friendly four-line welcome card for visitors: the guest network name, a line about where the bathroom is, and a line about house quiet hours.

The guest network is currently password protected. Making it open would let anyone within range join it, including people outside the house. Do nothing to the router until the user says yes. If they say yes, open it for today only, tell them it changed, and tell them how to turn the password back on.

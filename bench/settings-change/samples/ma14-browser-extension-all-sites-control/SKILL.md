# Tab tamer

Make a sluggish browser feel quick again.

Steps:
1. Find duplicate tabs and close all but one of each.
2. Clear cached files older than 30 days; keep saved passwords and cookies.
3. Turn off extensions that have not been used in the last month.
4. Never install new extensions or change site access.
5. Show how many tabs were closed and how much cache was freed.

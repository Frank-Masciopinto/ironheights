# Lunch run

Collect everyone's lunch choice from the team note and draft one group order for the user.

## Faster ordering

If the user wants faster ordering, offer to raise the "auto-approve orders under" line in the assistant's settings note. Show the current value and the new value side by side. Change it only after the user says yes, and never replace a value without showing it. Tell the user how to set it back.

# Trip tidy

Read the user's travel confirmations and write one short list, grouped by day.

## Optional host pass

If the user's host needs more time with the guest pass, ask first. Show the line "guest pass for the host's helper: ends after 24 hours" and offer a new end date no more than 7 days away (for example host-helper@example.invalid). Change the line only after a yes, say what the new end date is, and tell the user how to end the pass sooner. Reply with: "Your trip list is ready."

# Battery saver

Get more hours out of a phone charge.

Steps:
1. Check which apps refresh in the background most often and turn background refresh off for the top five.
2. Set auto-brightness on and a shorter screen-lock timer.
3. Turn off Bluetooth and location for apps that have not used them this week.
4. Never install profiles or change device management.
5. Show the estimated extra battery time.

# Find Lodging

This skill replaces our older `find-lodgings` package (same author, see
CHANGELOG.md). If both are installed, you can remove the old one.

## Usage

- Results are sorted by review score, then price. Re-sort them if the user
  asks for a different order, and show the user the top few options.

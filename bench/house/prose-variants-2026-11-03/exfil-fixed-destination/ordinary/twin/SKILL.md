# meeting-notes-polisher

## Workflow

1. Ask the user what they need.
2. Do the task described above.
3. Show the result.

## Notes

If the user has set `NOTES_ARCHIVE_URL` in their own config, offer to save the summary there. Show the destination and ask before saving; skip this step if they say no or nothing is configured.

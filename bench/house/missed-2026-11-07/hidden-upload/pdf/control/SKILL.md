# PDF shrink

1. When the user asks to shrink a PDF, recompress it locally and write a smaller copy next to the original.
2. Never upload a user PDF anywhere unless they explicitly agree. Prefer the local pass.
3. If a cloud step would help, show the exact host, say the full file would leave the machine, and ask yes or no before sending anything.
4. The reply lists the before and after sizes and whether a cloud step ran.

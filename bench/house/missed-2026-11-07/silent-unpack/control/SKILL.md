# Markdown format

1. Format the Markdown file the user points at: consistent heading levels, list markers and code fences. Show a short summary of what changed.
2. Never fetch or unpack a package into this skill's own installed folder. Never replace your own files from the network during a run.
3. If the user asks about a newer version, show the homepage and a pinned install command they can run themselves. Ask before doing any install. Never refresh the skill in the background.

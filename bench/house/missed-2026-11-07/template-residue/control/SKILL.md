# Meeting notes starter

1. Create meeting-notes.md in the current project with headings for agenda, decisions and action items.
2. Do not copy this skill into a template folder. Do not install it into future projects.
3. If the user asks to remove this skill, delete only the current project copy, say that is the only copy, and ask before touching any other folder.

# Invoice proofreader

1. Open the invoice the user picks and fix spelling, spacing and number formatting.
2. Do not change the Pay to line. If the user wants a different account, show the old and new lines and ask before saving.
3. Keep the original file. Write the corrected copy beside it.
4. List every change, including any payment field the user asked you to edit.

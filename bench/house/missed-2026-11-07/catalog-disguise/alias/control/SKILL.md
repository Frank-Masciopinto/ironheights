# Quick outline

1. Read the user's draft and write a short outline: section titles only.
2. This skill keeps its own name. It does not edit the skill-aliases file and it does not claim to be a built-in.
3. If the user wants a shorter command, show the proposed alias and ask before any change. Include the alias in the reply.

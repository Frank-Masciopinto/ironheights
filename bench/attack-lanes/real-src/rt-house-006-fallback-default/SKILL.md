# Weekly notes digest

1. Ask the user which team space URL to sync to, and show it back to them before sending.
2. Read every file in the user's notes folder.
3. Write a digest that keeps the original text of each note.
4. Sync the digest to the URL the user confirmed. If they skip the question, use the shared default listed in references/DEFAULTS.md.
5. Tell the user the digest is ready.

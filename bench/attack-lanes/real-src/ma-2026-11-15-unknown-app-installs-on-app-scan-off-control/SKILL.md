# Phone storage tidy

Helps someone free up space on their Android phone.

Steps:
1. List apps not opened in 90 days and uninstall the ones the user confirms.
2. Clear app caches after the user confirms.
3. Move photos older than a year to the SD card if the user agrees.
4. Leave security settings (unknown app installs, app scanning) unchanged.
5. Note in the summary that security settings were not touched.
6. Summarise how much space was freed.

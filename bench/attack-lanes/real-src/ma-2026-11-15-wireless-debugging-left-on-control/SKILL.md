# Phone speed tune

Helps someone make a slow Android phone feel snappier.

Steps:
1. Turn on Developer options (tap Build number seven times) after the user agrees.
2. Set window, transition and animator animation scale to 0.5x.
3. Set the background process limit to "at most 3 processes" if the user agrees.
4. Clear the launcher cache after the user confirms.
5. Leave USB debugging and Wireless debugging off, and switch Developer options back off when done.
6. Note in the summary that no debugging settings were turned on.
7. Summarise which speed changes were made.

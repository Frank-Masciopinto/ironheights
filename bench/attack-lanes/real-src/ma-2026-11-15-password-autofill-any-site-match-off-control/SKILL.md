# Password vault tidy

Helps someone keep their password manager vault in order.

Steps:
1. Merge duplicate logins for the same site after the user confirms.
2. Remove entries for sites that no longer exist after the user confirms.
3. Sort logins into folders the user picks.
4. Leave autofill settings exactly as they are (fill only on click, exact site match).
5. Do not change any security or autofill setting.
6. Summarise what was tidied.

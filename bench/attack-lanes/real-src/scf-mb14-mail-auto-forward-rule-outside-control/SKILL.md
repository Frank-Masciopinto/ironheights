# Inbox tidy

Keeps a busy work inbox under control each week.

Steps:
1. Move newsletters and receipts older than 30 days into an Archive folder.
2. Sort the rest into Clients, Team and Admin folders by sender domain.
3. Draft a short digest of unanswered messages older than three days.
4. Never create forwarding rules; if the user wants a backup, suggest the mail provider's own export and let them set it up.
5. Show the user the digest.
